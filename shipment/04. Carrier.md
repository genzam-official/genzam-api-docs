# Carrier

> **Description:** Fetches available shipping carriers, rates, transit times, and service details based on the origin, destination, and package dimensions.

---

## Endpoint Details

- **Endpoint:** `/carrier`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/carrier`

---

## Request Body Specification

The request payload requires origin (`from`), destination (`to`), and an array of `packages`.

### Request Parameters

| Field               | Type     | Description                                                                   |
| :------------------ | :------- | :---------------------------------------------------------------------------- |
| `from.country`      | `string` | Origin country code (ISO code from `/postal-zone` endpoint, e.g., `IT`).      |
| `from.zip`          | `string` | Origin postal code / zip (e.g., `80036`).                                     |
| `to.country`        | `string` | Destination country code (ISO code from `/postal-zone` endpoint, e.g., `BD`). |
| `to.zip`            | `string` | Destination postal code / zip (e.g., `6600`).                                 |
| `packages`          | `array`  | List of package objects specifying dimensions and weight.                     |
| `packages[].weight` | `number` | Package weight in **kg**.                                                     |
| `packages[].width`  | `number` | Package width in **cm**.                                                      |
| `packages[].height` | `number` | Package height in **cm**.                                                     |
| `packages[].length` | `number` | Package length in **cm**.                                                     |

---

## Example Request Payload

```json
{
  "from": {
    "country": "IT",
    "zip": "80036"
  },
  "to": {
    "country": "BD",
    "zip": "6600"
  },
  "packages": [
    {
      "weight": 1,
      "width": 10,
      "height": 10,
      "length": 10
    }
  ]
}
```
