# Packages Data Structure

> **Note:** Packages must be sent as an array of objects representing the physical dimensions and weight of each package. Shipment creation additionally requires a string `id` and `name` for every package.

---

## Field Specifications

| Field    | Type     | Unit   | Description                                                                 |
| :------- | :------- | :----- | :-------------------------------------------------------------------------- |
| `weight` | `number` | **kg** | The total weight of the package.                                            |
| `width`  | `number` | **cm** | The width dimension of the package.                                         |
| `height` | `number` | **cm** | The height dimension of the package.                                        |
| `length` | `number` | **cm** | The length dimension of the package.                                        |
| `id`     | `string` | -      | Required when creating or updating a shipment. Identifies the package.      |
| `name`   | `string` | -      | Required when creating or updating a shipment. Human-readable package name. |

---

## Examples

### Single Package Example

```json
{
  "packages": [
    {
      "weight": 1,
      "width": 10,
      "height": 10,
      "length": 10
    }
  ]
}
```

### Multiple Packages Example

```json
{
  "packages": [
    {
      "weight": 1.5,
      "width": 10,
      "height": 10,
      "length": 10
    },
    {
      "weight": 3.0,
      "width": 25,
      "height": 15,
      "length": 20
    },
    {
      "weight": 0.5,
      "width": 5,
      "height": 5,
      "length": 5
    }
  ]
}
```
