# Postal Code

## Endpoint Details

- **Endpoint:** `/postal-code`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/postal-code?q=80036&postalzone=113`

### Query Parameters

| Parameter    | Type     | Allowed Values             | Description                                                              |
| :----------- | :------- | :------------------------- | :----------------------------------------------------------------------- |
| `q`          | `string` | Any string (e.g., `80036`) | Filters postal codes by postal code value or city name.                  |
| `postalzone` | `string` | Numeric ID (e.g., `113`)   | Filters postal codes by `id` retrieved from the `/postal-zone` endpoint. |
