# Product Price

> **Description:** Fetches detailed pricing items (base service price, insurance, platform fees, taxes, and totals) for a specific shipping carrier service based on declared item value, locations, parcel details, and customs documents.

---

## Endpoint Details

- **Endpoint:** `/product-price`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/product-price`

---

## Request Body Specification

### Request Parameters

| Field                          | Type      | Description                                                                            |
| :----------------------------- | :-------- | :------------------------------------------------------------------------------------- |
| `service_id`                   | `number`  | The carrier service identifier (retrieved from the `id` field in `/carrier` response). |
| `contentvalue`                 | `number`  | Declared monetary value of the goods being shipped.                                    |
| `content_second_hand`          | `boolean` | Set to `true` if goods are second-hand, or `false` if brand new.                       |
| `proof_of_delivery`            | `boolean` | Set to `true` to request proof of delivery service.                                    |
| `from`                         | `object`  | Origin location details.                                                               |
| `from.city`                    | `string`  | Origin city (e.g., `Palma Campania`).                                                  |
| `from.country`                 | `string`  | Origin country ISO code (e.g., `IT`).                                                  |
| `from.state`                   | `string`  | Origin state or region (e.g., `Italy`).                                                |
| `from.zip_code`                | `string`  | Origin postal code / zip (e.g., `80036`).                                              |
| `from.street1`                 | `string`  | Origin street address (e.g., `Piazza Antonio De Martino 64...`).                       |
| `to`                           | `object`  | Destination location details.                                                          |
| `to.city`                      | `string`  | Destination city (e.g., `Pabna Sadar`).                                                |
| `to.country`                   | `string`  | Destination country ISO code (e.g., `BD`).                                             |
| `to.state`                     | `string`  | Destination state or region (e.g., `Bangladesh`).                                      |
| `to.zip_code`                  | `string`  | Destination postal code / zip (e.g., `6600`).                                          |
| `insurance`                    | `object`  | Insurance/protection preferences.                                                      |
| `insurance.amount`             | `number`  | Total monetary value to insure the shipment for.                                       |
| `insurance.insurance_selected` | `boolean` | Set to `true` to enable extra insurance coverage.                                      |
| `customs`                      | `object`  | Customs information object for international shipments.                                |
| `customs.customs_invoice_id`   | `string`  | UUID reference for generated customs invoice. Create via /customs-invoice endpoint.    |
| `packages`                     | `array`   | Array of package dimension/weight objects.                                             |
| `packages[].weight`            | `number`  | Package weight in **kg**.                                                              |
| `packages[].width`             | `number`  | Package width in **cm**.                                                               |
| `packages[].height`            | `number`  | Package height in **cm**.                                                              |
| `packages[].length`            | `number`  | Package length in **cm**.                                                              |

## Response Structure

### Response Fields

| Field                                | Type                  | Description                                                                                        |
| ------------------------------------ | --------------------- | -------------------------------------------------------------------------------------------------- |
| `success`                            | `boolean`             | Indicates if the request was processed successfully (`true`).                                      |
| `message`                            | `string`              | Status message regarding the response.                                                             |
| `data.products`                      | `array`               | List of breakdown line items included in the final calculation.                                    |
| `data.products[].key`                | `string`              | System key identifier for the price component (e.g., `porterage`, `insurance`, `management_fee`).  |
| `data.products[].label`              | `string`              | Human-readable name of the fee item (e.g., `Service Price`, `Service Protection`, `Platform Fee`). |
| `data.products[].base_price`         | `number`              | Pre-tax base cost for this line item.                                                              |
| `data.products[].tax_price`          | `number`              | Calculated tax/VAT amount for this line item.                                                      |
| `data.products[].total_price`        | `number`              | Combined total cost (`base_price` + `tax_price`) for this line item.                               |
| `data.products[].currency`           | `string`              | Currency code (e.g., `EUR`).                                                                       |
| `data.products[].is_enabled`         | `boolean`             | Indicates if this option is available for selection.                                               |
| `data.products[].is_selected`        | `boolean`             | Indicates if this price component is active in the order.                                          |
| `data.products[].protection_value`   | `number` _(optional)_ | Insured value applied (present on `insurance` item).                                               |
| `data.products[].taxes`              | `array`               | Applied tax rates for this line item.                                                              |
| `data.products[].taxes[].percentage` | `number`              | Tax rate percentage (e.g., `22` for 22% VAT).                                                      |
| `data.products[].taxes[].identifier` | `string`              | Tax classification code (e.g., `S4`).                                                              |
| `data.products[].taxes[].name`       | `string`              | Name of the tax type (e.g., `VAT`).                                                                |
| `data.total`                         | `object`              | Grand total calculation for all active line items.                                                 |
| `data.total.base_price`              | `number`              | Aggregate base price of all components.                                                            |
| `data.total.tax_price`               | `number`              | Aggregate tax amount across all components.                                                        |
| `data.total.total_price`             | `number`              | Final total amount payable.                                                                        |
| `data.total.currency`                | `string`              | Currency of total price.                                                                           |
| `data.total.taxes`                   | `array`               | Summary of tax breakdown for the total cost.                                                       |
