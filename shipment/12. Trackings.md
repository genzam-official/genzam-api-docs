# Shipment Trackings

> **Description:** Retrieves carrier tracking details together with the locally stored shipment details for an order.

## Endpoint details

- **Endpoint:** `/trackings`
- **Method:** `GET`
- **Authentication:** API key with the `shipmentsApi` and `shipmentsApiTrackings` features enabled.
- **Example request URL:** `${baseUrl}/trackings?order_id=cargo-933bd924d3d7`

## Query parameters

| Parameter  | Type     | Required | Description                                                           |
| ---------- | -------- | -------- | --------------------------------------------------------------------- |
| `order_id` | `string` | Yes      | The generated shipment order ID stored in `additional_data.order_id`. |

## Response

The response contains the upstream carrier tracking data and the locally stored shipment data. Internal provider identifiers and `public_tracking_url` are omitted from the local shipment object before it is returned.

```json
{
  "success": true,
  "message": "Shipment trackings retrieved successfully.",
  "data": {
    "tracking_details": {},
    "shipment_details": {}
  }
}
```

A missing `order_id` returns `400`. If the order cannot be found or the upstream tracking request fails, the endpoint returns `500` with an `error` field.
