# Dropoff Point

> **Description:** Retrieves nearby drop-off or pick-up locations (parcel shops, lockers, or service points) for a specific carrier service based on location coordinates or address and parcel details.

---

## Endpoint Details

- **Endpoint:** `/dropoff-point`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/dropoff-point`

---

## Request Body Specification

### Request Parameters

| Field               | Type     | Allowed Values            | Description                                                      |
| :------------------ | :------- | :------------------------ | :--------------------------------------------------------------- |
| `service_id`        | `number` | Numeric ID                | Carrier service identifier (retrieved from `/carrier` endpoint). |
| `points_type`       | `string` | `"drop-off"`, `"pick-up"` | Filter location type by drop-off or pick-up point.               |
| `location`          | `object` | Object                    | Target location criteria to locate nearby service points.        |
| `location.country`  | `string` | Country ISO code          | ISO country code (e.g., `IT`).                                   |
| `location.zip_code` | `string` | Postal code               | Postal code / Zip (e.g., `80014`).                               |
| `location.city`     | `string` | City name                 | City name (e.g., `Giugliano in Campania`).                       |
| `packages`          | `array`  | Array                     | List of package dimension/weight objects.                        |
| `packages[].weight` | `number` | Positive number           | Package weight in **kg**.                                        |
| `packages[].width`  | `number` | Positive number           | Package width in **cm**.                                         |
| `packages[].height` | `number` | Positive number           | Package height in **cm**.                                        |
| `packages[].length` | `number` | Positive number           | Package length in **cm**.                                        |

---

### Example Request Payload

```json
{
  "location": {
    "country": "IT",
    "zip_code": "80014",
    "city": "Giugliano in Campania"
  },
  "packages": [
    {
      "height": 10,
      "length": 10,
      "weight": 1,
      "width": 10
    }
  ],
  "points_type": "drop-off",
  "service_id": 23303
}
```

---

## Response Structure

### Response Fields

| Field                  | Type      | Description                                                    |
| :--------------------- | :-------- | :------------------------------------------------------------- |
| `success`              | `boolean` | Indicates if request processed successfully (`true`).          |
| `message`              | `string`  | API status message.                                            |
| `data`                 | `array`   | List of drop-off or pick-up points matching location criteria. |
| `data[].id`            | `string`  | Unique service point identifier.                               |
| `data[].commerce_name` | `string`  | Business or store name operating the point.                    |
| `data[].address`       | `string`  | Street address of location.                                    |
| `data[].city`          | `string`  | City where point is located.                                   |
| `data[].state`         | `string`  | State or province abbreviation (e.g., `NA`).                   |
| `data[].zip`           | `string`  | Postal code / Zip code.                                        |
| `data[].country`       | `string`  | ISO 2-letter country code (e.g., `IT`).                        |
| `data[].lat`           | `number`  | Latitude geographic coordinate.                                |
| `data[].long`          | `number`  | Longitude geographic coordinate.                               |
| `data[].phone`         | `string`  | Contact phone number for service point (if available).         |
| `data[].carrier`       | `string`  | Associated shipping carrier network (e.g., `Inpost IT`).       |
| `data[].type`          | `string`  | Specific point type category.                                  |
| `data[].opening_times` | `object`  | Operating hours schedule by day.                               |
