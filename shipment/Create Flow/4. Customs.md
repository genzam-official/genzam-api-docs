# Customs

Use this step for international shipments that require a customs invoice. First load the supported countries, then create and store the signed customs invoice ID.

![Customs step](<images/4. Customs.png>)

## Countries

### Endpoint

`${baseUrl}/shipments/country`

**Method:** `GET`

### Response:

```json
{
  "success": true,
  "message": "All shipment countries retrieved successfully.",
  "data": {
    "items": [
      {
        "name": "Afghanistan",
        "alpha2Code": "AF"
      },
      {
        "name": "Albania",

      }
    ],
    "totalPages": 1,
    "currentPage": 1,
    "totalItems": 250,
    "limit": 500,
    "skip": 0
  }
}
```
