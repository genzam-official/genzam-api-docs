## Recalculate product prices

Call the product price endpoint again after the address, contents, and insurance fields are complete. Use the request format documented in [Address: pickup and delivery](<3. Address - Pickup-Delivery.md>).

## Drop-off points

`POST https://api.genzam.it/api/v1/shipments/dropoff-point`

**Authorization:** `Bearer api_key`

### Endpoint

`${baseUrl}/shipments/dropoff-point`

**Method:** `POST`

### Request body

```json
{
  "service_id": 23863,
  "location": {
    "zip_code": "80036",
    "city": "Palma Campania",
    "country": "IT"
  },
  "points_type": "pick-up",
  "packages": [
    {
      "weight": 1,
      "length": 10,
      "width": 10,
      "height": 10,
      "id": "custom-parcel-id-1",
      "name": "custom-parcel-1"
    }
  ]
}
```
