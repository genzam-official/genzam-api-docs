# Shipment Details

Use this step to load origin and destination postal zones, search postal codes, and retrieve saved sender addresses before building the shipment draft.

![Shipment details step](<images/1. Shipment Details Step.png>)

## Authentication

Every request must include the API key as a bearer token.

```http
Authorization: Bearer api_key
```

```text
baseUrl = https://api.genzam.it/api/v1
```

## From postal zone

### Endpoint

`${baseUrl}/shipments/postal-zone`

**Method:** `GET`

**Query parameters:**

```json
{
  "location": "origins"
}
```

### Example

`${baseUrl}/shipments/postal-zone?location=origins`

**Response:**

```json
{
  "success": true,
  "message": "All shipment postal zones retrieved successfully.",
  "data": {
    "items": [
      {
        "id": "1",
        "name": "Afghanistan",
```

## Shipment draft

```json
{
  "packages": [
    {
      "weight": 1,
      "length": 10,
      "width": 10,
      "height": 10,
      "id": "custom-parcel-id-1",
      "name": "custom-parcel-1"
    }
  ],
  "from": {
    "zip_code": "80014",
    "city": "Giugliano in Campania",
    "country": "IT",
    "state": "Italy"
  },
  "to": {
    "zip_code": "80036",
    "city": "Palma Campania",
    "country": "IT",
    "state": "Italy"
  },
  "additional_data": {
```
