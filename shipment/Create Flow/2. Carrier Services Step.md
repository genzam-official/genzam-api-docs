# Choose a carrier service

Use the shipment draft from the previous step to retrieve available carrier services and prices.

![Carrier services step](<images/2. Carrier Services Step.png>)

`POST https://api.genzam.it/api/v1/shipments/carrier`

**Authorization:** `Bearer api_key`

## Request and response

### Endpoint

`${baseUrl}/shipments/carrier`

**Method:** `POST`

### Request body

```json
{
  "from": {
    "country": "IT",
    "zip": "80014"
  },
  "to": {
    "country": "IT",
    "zip": "80036"
  },
  "packages": [
    {
      "weight": 1,
      "length": 10,
      "width": 10,
      "height": 10,
      "id": "custom-parcel-id-1",
      "name": "custom-parcel-1"
    }
  ]
}
```
