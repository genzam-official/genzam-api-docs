# Create a shipment: drop-off and pickup

Create a shipment where the sender drops the parcel at a carrier point and the recipient collects it from a pickup point.

![Shipment creation flow](<images/5. Shipment Creation.png>)

## Endpoint

`${baseUrl}/shipments`

**Method:** `POST`
