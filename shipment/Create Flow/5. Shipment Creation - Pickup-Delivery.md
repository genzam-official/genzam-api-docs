# Create a shipment: pickup and delivery

Create a shipment where the carrier collects the parcel from the sender and delivers it to the recipient.

![Shipment creation flow](<images/5. Shipment Creation.png>)

## Endpoint

`${baseUrl}/shipments`

**Method:** `POST`
