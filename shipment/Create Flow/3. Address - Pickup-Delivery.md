# Address: pickup and delivery

Complete the sender and recipient information, choose a collection slot, and calculate the final product price before creating the shipment.

![Pickup and delivery address step](<images/3. Address - Pickup-Delivery.png>)

## Content options

```json
[
  { "label": "Electronics", "value": "Electronics" },
  { "label": "Mobile phones", "value": "Mobile phones" },
  { "label": "Clothing", "value": "Clothing" },
  { "label": "Furniture", "value": "Furniture" },
  { "label": "Food", "value": "Food" },
  { "label": "Books", "value": "Books" },
  {
    "label": "Documents (Exclusions Apply)",
    "value": "Documents (Exclusions Apply)"
  },
  { "label": "Other", "value": "Other" }
]
```

## Product prices

`POST https://api.genzam.it/api/v1/shipments/product-price`

**Authorization:** `Bearer api_key`

### Request body

```json
{
  "content_second_hand": true,
  "contentvalue": 500,
  "from": {
    "city": "Giugliano in Campania",
    "country": "IT",
    "state": "Italy",
    "zip_code": "80014"
  },
  "insurance": {
    "amount": 500,
    "insurance_selected": true
  },
  "service_id": 20203,
  "to": {
    "city": "Palma Campania",
    "country": "IT",
    "state": "Italy",
    "zip_code": "80036"
  },
  "customs": {},
  "packages": [
    {
      "weight": 1,
      "length": 10,
      "width": 10,
      "height": 10,
      "id": "custom-parcel-id-1",
      "name": "custom-parcel-1"
    }
  ]
}
```
