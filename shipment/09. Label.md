# Label

> **Description:** Retrieves a downloadable shipping label PDF link for a created shipment using its order ID and desired paper format.

---

## Endpoint Details

- **Endpoint:** `/label`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/label?order_id=cargo-933bd924d3d7&format=A6`

---

## Query Parameters

| Parameter  | Type     | Allowed Values          | Description                                       |
| :--------- | :------- | :---------------------- | :------------------------------------------------ |
| `order_id` | `string` | String                  | Shipment order ID used to locate the shipment.    |
| `format`   | `string` | `"A6"`, `"COMBINED_A4"` | Output paper print format for shipping label PDF. |

---

## Response Structure

### Response Fields

| Field     | Type      | Description                                              |
| :-------- | :-------- | :------------------------------------------------------- |
| `success` | `boolean` | Indicates if request processed successfully (`true`).    |
| `message` | `string`  | API status message.                                      |
| `data`    | `string`  | Direct downloadable URL for the shipping label PDF file. |

---

### `200 OK` Response Example

```json
{
  "success": true,
  "message": "Shipment labels retrieved successfully.",
  "data": "https://api.eu.shipengine.com/v1/downloads/10/HOvNuT1030OIFqgCg5PrIA/label-832292867.pdf"
}
```
