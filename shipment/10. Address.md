# Address Management

> **Description:** Manage saved sender and receiver shipment addresses for a user profile. Allows creating, updating, deleting, retrieving with search/pagination, and toggling default address selections.

---

## Business Rules & Constraints

- **Maximum Limit:** Users can save a maximum of **8 sender** addresses and **8 receiver** addresses.
- **Duplicate Prevention:** Addresses matching an existing combination of `address`, `postal_code`, `city`, and `country` for the same `address_type` will be rejected.
- **Conditional Validation:**
  - If `user_type` is `"COMPANY"`, `company` and `vat_number` are required fields.
  - If `user_type` is `"PRIVATE_PERSON"`, `tax_id` is required.
- **Default Selection:** Setting an address as default (`default_selection: true`) automatically unsets default status for all other saved addresses of that same `address_type`.

## 1. Create Shipment Address

### Endpoint Details

- **Endpoint:** `/address`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/address`

### Request Body Specification

| Field               | Type      | Allowed Values                  | Description                                                                        |
| :------------------ | :-------- | :------------------------------ | :--------------------------------------------------------------------------------- |
| `address_type`      | `string`  | `"sender"`, `"receiver"`        | Classification of the address record.                                              |
| `alias`             | `string`  | String (1–150 chars)            | Friendly name/nickname for the saved address (e.g., `"Home Office"`).              |
| `name`              | `string`  | String (1–150 chars)            | First name of contact.                                                             |
| `surname`           | `string`  | String (1–150 chars)            | Last name of contact.                                                              |
| `email`             | `string`  | Valid email string              | Contact email address.                                                             |
| `phone`             | `string`  | String (1–30 chars)             | Contact phone number.                                                              |
| `address`           | `string`  | String (1–150 chars)            | Street address line.                                                               |
| `city`              | `string`  | String (1–150 chars)            | City name.                                                                         |
| `country`           | `string`  | ISO 2-letter code               | Country code (e.g., `"IT"`, `"BD"`).                                               |
| `postal_code`       | `string`  | String (1–150 chars)            | Zip / Postal code value.                                                           |
| `postal_code_id`    | `string`  | String                          | System identifier from `/postal-code` endpoint.                                    |
| `postal_zone`       | `object`  | Object                          | Postal zone details containing `id` and localized `translations`.                  |
| `user_type`         | `string`  | `"PRIVATE_PERSON"`, `"COMPANY"` | Account classification of address contact.                                         |
| `company`           | `string`  | String (max 150 chars)          | Company name (Required if `user_type` is `"COMPANY"`).                             |
| `vat_number`        | `string`  | String (max 150 chars)          | VAT ID number (Required if `user_type` is `"COMPANY"`).                            |
| `tax_id`            | `string`  | String (max 150 chars)          | Personal tax code/SSN/Passport ID (Required if `user_type` is `"PRIVATE_PERSON"`). |
| `eori_number`       | `string`  | String                          | EORI customs identification number (optional).                                     |
| `ukims_number`      | `string`  | String                          | UKIMS Scheme registration number (optional).                                       |
| `default_selection` | `boolean` | `true`, `false`                 | Whether to mark this address as default (default: `false`).                        |

## 2. Get All Saved Addresses

### Endpoint Details

- **Endpoint:** `/address/all`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/address/all?address_type=sender&page=1&limit=10&search=Genzam`

### Query Parameters

| Parameter      | Type     | Default  | Allowed Values           | Description                                                              |
| :------------- | :------- | :------- | :----------------------- | :----------------------------------------------------------------------- |
| `address_type` | `string` | Optional | `"sender"`, `"receiver"` | Filter addresses by sender or receiver type.                             |
| `search`       | `string` | Optional | String                   | Search keyword matching name, email, company, address, city, phone, etc. |
| `page`         | `number` | `1`      | Numeric                  | Page number for pagination.                                              |
| `limit`        | `number` | `10`     | Numeric                  | Maximum records per page.                                                |

#### `200 OK` Response Example

```json
{
  "success": true,
  "message": "All shipment addresses retrieved successfully.",
  "data": {
    "items": [
      {
        "_id": "66f1bfd82a138c201d4a1b02",

        "alias": "Main Warehouse",
        "name": "Mario",
        "surname": "Rossi",
        "company": "Genzam IT",
        "email": "mario.rossi@example.com",
        "phone": "+390612345678",
        "address": "Piazza Antonio De Martino 64",
        "city": "Palma Campania",
```
