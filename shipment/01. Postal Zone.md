# Postal Zone API Documentation

> **Important:** Cache this data and store it in your own database. Check for updates weekly to account for any changes.

## Endpoint Details

- **Endpoint:** `/postal-zone`
- **HTTP Method:** `GET`
- **Example Query URL:** `${baseUrl}/postal-zone?location=origins&search=Italy&page=1&limit=500`

### Query Parameters

| Parameter  | Type     | Allowed Values                | Description                                          |
| ---------- | -------- | ----------------------------- | ---------------------------------------------------- |
| `location` | `string` | `"origins"`, `"destinations"` | Filters postal zones by location type.               |
| `search`   | `string` | Optional                      | Searches by country name, ISO code, or phone prefix. |
| `page`     | `number` | `1`                           | Page number.                                         |
| `limit`    | `number` | `500`                         | Maximum number of records returned.                  |
