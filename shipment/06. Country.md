# Country

> **Caching Strategy:** You should cache this data and call it from your own database. Also check for updates every week for any changes.

---

## Endpoint Details

- **Endpoint:** `/country`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/country?search=Italy&page=1&limit=500`

---

## Query Parameters

| Parameter | Type     | Default  | Description                           |
| --------- | -------- | -------- | ------------------------------------- |
| `search`  | `string` | Optional | Searches country names and ISO codes. |
| `page`    | `number` | `1`      | Page number.                          |
| `limit`   | `number` | `500`    | Maximum number of records returned.   |

---

## Response Structure

### Response Fields

| Field                     | Type      | Description                                                           |
| :------------------------ | :-------- | :-------------------------------------------------------------------- |
| `success`                 | `boolean` | Indicates if the request was processed successfully (`true`).         |
| `message`                 | `string`  | Status message regarding the response.                                |
| `data.items`              | `array`   | List of country objects containing country name and ISO alpha-2 code. |
| `data.items[].name`       | `string`  | Full display name of the country.                                     |
| `data.items[].alpha2Code` | `string`  | Two-letter ISO country code (e.g., `AF`, `AL`).                       |
| `data.totalPages`         | `number`  | Total number of pages available.                                      |
| `data.currentPage`        | `number`  | Current page number.                                                  |
| `data.totalItems`         | `number`  | Total count of countries retrieved.                                   |
| `data.limit`              | `number`  | Maximum items returned per request.                                   |
| `data.skip`               | `number`  | Number of items skipped for pagination.                               |

---
