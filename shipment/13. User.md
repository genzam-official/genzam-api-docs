# User Balance

Manage the authenticated user's test balance and view current account balances.

## Refill test balance

### Endpoint

`${baseUrl}/users/refill-test-balance`

**Method:** `POST`

When the current `testBalance` is less than `500`, this endpoint adds `500` to the test balance. If the current balance is `500` or higher, no additional test balance is added and throws error.

### Response

```json
{
  "message": "User test balance refilled successfully",
  "data": {
    "_id": "USER_ID",
    "testBalance": 652.85,
    "username": "example_user"
  },
  "success": true
}
```

## Get user balances

### Endpoint

`${baseUrl}/users/balances`

**Method:** `GET`

### Response

```json
{
  "message": "User balances retrieved successfully",
  "data": {
    "_id": "USER_ID",
    "username": "example_user",
    "testBalance": 652.85,
    "domesticBalance": 48848.33
  },
  "success": true
}
```
