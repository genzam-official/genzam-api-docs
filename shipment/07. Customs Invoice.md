# Customs Invoice

> **Description:** Manage customs invoice declarations for international shipments. Provides endpoints to create a new customs invoice record and download the generated PDF invoice file.

---

## 1. Create Customs Invoice

### Endpoint Details

- **Endpoint:** `/customs-invoice`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/customs-invoice`

---

### Request Body Specification

#### Request Parameters

| Field                                         | Type     | Description                                                                               |
| :-------------------------------------------- | :------- | :---------------------------------------------------------------------------------------- |
| `reason_for_export`                           | `string` | Purpose of international export (e.g., `PURCHASE_OR_SALE`, `GIFT`, `DOCUMENT`, `SAMPLE`). |
| `invoice_number`                              | `string` | Unique seller invoice reference or bill number (e.g., `inv-1234`).                        |
| `inventory_of_contents`                       | `array`  | List of item objects declared inside the shipment.                                        |
| `inventory_of_contents[].tariff_number`       | `string` | HS / Harmonized System tariff code identifying the commodity (e.g., `123456`).            |
| `inventory_of_contents[].description`         | `string` | Detailed description of the declared item.                                                |
| `inventory_of_contents[].country_of_origin`   | `string` | ISO 2-letter country code where the item was manufactured (e.g., `CN`).                   |
| `inventory_of_contents[].item_value`          | `object` | Value declaration per item unit.                                                          |
| `inventory_of_contents[].item_value.value`    | `number` | Monetary value per unit.                                                                  |
| `inventory_of_contents[].item_value.currency` | `string` | ISO currency code (e.g., `EUR`).                                                          |
| `inventory_of_contents[].item_weight`         | `number` | Unit weight of the item in **kg**.                                                        |
| `inventory_of_contents[].quantity`            | `number` | Quantity count of this declared item.                                                     |
| `sender`                                      | `object` | Sender address and legal information.                                                     |
| `sender.user_type`                            | `string` | Classification of entity (`COMPANY` or `PRIVATE_PERSON`).                                 |
| `sender.full_name`                            | `string` | Full contact name for sender.                                                             |
| `sender.company_name`                         | `string` | Registered legal name of sender company (if applicable).                                  |
| `sender.vat_number`                           | `string` | VAT identification number of sender.                                                      |
| `sender.eori_number`                          | `string` | Economic Operators Registration and Identification (EORI) number of sender.               |
| `sender.address`                              | `string` | Street address of sender.                                                                 |
| `sender.postal_code`                          | `string` | Postal / Zip code of sender.                                                              |
| `sender.city`                                 | `string` | Sender city name.                                                                         |
| `sender.country`                              | `string` | ISO 2-letter sender country code (e.g., `IT`).                                            |
| `sender.phone_number`                         | `string` | Sender contact telephone number.                                                          |
| `receiver`                                    | `object` | Recipient address and legal information.                                                  |
| `receiver.user_type`                          | `string` | Classification of entity (`COMPANY` or `PRIVATE_PERSON`).                                 |
| `receiver.full_name`                          | `string` | Full contact name for receiver.                                                           |
| `receiver.tax_id`                             | `string` | Receiver tax identification, SSN, or passport number.                                     |
| `receiver.address`                            | `string` | Receiver destination street address.                                                      |
| `receiver.postal_code`                        | `string` | Receiver postal / Zip code.                                                               |
| `receiver.city`                               | `string` | Receiver city name.                                                                       |
| `receiver.country`                            | `string` | ISO 2-letter receiver country code (e.g., `BD`).                                          |
| `receiver.phone_number`                       | `string` | Receiver contact telephone number.                                                        |
| `shipment_details`                            | `object` | Physical totals for the consignment.                                                      |
| `shipment_details.parcels_size`               | `number` | Total count of packages in the shipment.                                                  |
| `shipment_details.parcels_weight`             | `number` | Total aggregate weight of all packages in **kg**.                                         |
| `shipment_details.cost`                       | `object` | Estimated carriage / shipping fee details.                                                |
| `shipment_details.cost.value`                 | `number` | Total shipping cost value.                                                                |
| `shipment_details.cost.currency`              | `string` | ISO currency code (e.g., `EUR`).                                                          |

### Response Structure

#### Response Fields

| Field                             | Type      | Description                                                                                              |
| :-------------------------------- | :-------- | :------------------------------------------------------------------------------------------------------- |
| `success`                         | `boolean` | Indicates if the request was processed successfully (`true`).                                            |
| `message`                         | `string`  | API status message.                                                                                      |
| `data.id`                         | `string`  | Unique UUID identifier for created customs invoice (used to attach to `/product-price` or download PDF). |
| `data.created_at`                 | `string`  | ISO timestamp of creation.                                                                               |
| `data.updated_at`                 | `string`  | ISO timestamp of last update.                                                                            |
| `data.status`                     | `string`  | Invoice status (e.g., `SIGNED`, `DRAFT`, `PENDING`).                                                     |
| `data.data.invoice_number`        | `string`  | Stored invoice number reference.                                                                         |
| `data.data.sender`                | `object`  | Stored sender profile data.                                                                              |
| `data.data.sender.ukims_number`   | `string`  | UK Internal Market Scheme number (if applicable).                                                        |
| `data.data.receiver`              | `object`  | Stored receiver profile data.                                                                            |
| `data.data.inventory_of_contents` | `array`   | Stored inventory list.                                                                                   |
| `data.data.reason_for_export`     | `string`  | Stored export reason.                                                                                    |
| `data.data.shipment_details`      | `object`  | Stored shipment dimension and cost totals.                                                               |
| `data.data.at_risk`               | `boolean` | Risk assessment classification flag for customs compliance.                                              |

## 2. Download Customs Invoice

### Endpoint Details

- **Endpoint:** `/customs-invoice/:id`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/customs-invoice/18f2c9f6-3c38-443e-baa7-d54124e144fd`

---

### Path Parameters

| Parameter | Type     | Description                                       |
| :-------- | :------- | :------------------------------------------------ |
| `id`      | `string` | The UUID of the generated customs invoice record. |

---

### Response Structure

#### Response Fields

| Field     | Type      | Description                                                   |
| :-------- | :-------- | :------------------------------------------------------------ |
| `success` | `boolean` | Indicates if the request was processed successfully (`true`). |
| `message` | `string`  | API status message.                                           |
| `data`    | `string`  | Direct URL link to download the generated PDF document.       |

#### `200 OK` Response Example

```json
{
  "success": true,
  "message": "Shipment customs invoice retrieved successfully.",
  "data": "https://shipment.genzam.com/customs-invoices/18f2c9f6-3c38-443e-baa7-d54124e144fd.pdf"
}
```
