# Shipment Management

> **Description:** Provides shipment creation, update, listing, and retrieval. Shipment deletion is not currently exposed by the public router.

---

## Business Rules & Constraints

- **Service Verification:** During creation, the endpoint automatically validates that the specified `service_id` exists and is available for the given origin, destination, and package sizes.
- **Customs Requirement:** If the carrier service requires customs clearance (`service.customs_required`), `customs.customs_invoice_id` must be provided in the payload.
- **Parcelshop Requirement:** If the carrier service involves delivery or drop-off at a parcel shop (`service.delivery_to_parcelshop`), a valid `dropoff_point_id` must be provided.
- **Flexible Identification:** The Get by ID endpoint (`GET /:id`) accepts a MongoDB `_id` or generated `cargo-*` order ID.
- **Server-derived Service Data:** The public request needs `service_id`; the server resolves and stores `carrier`, `service`, `carrier_product_id`, pricing, and service metadata from the selected carrier service.
- **Generated Order ID:** The server adds a generated `cargo-*` value to `additional_data.order_id` when the shipment is stored.

## 1. Create Shipment

### Endpoint Details

- **Endpoint:** `/`
- **Method:** `POST`
- **Example Request URL:** `${baseUrl}/`

---

### Request Body Specification

#### Request Parameters

| Field                                   | Type      | Required    | Description                                                         |
| :-------------------------------------- | :-------- | :---------- | :------------------------------------------------------------------ |
| `service_id`                            | `number`  | **Yes**     | Carrier service ID selected from `/carrier` response.               |
| `content`                               | `string`  | **Yes**     | General text description of package contents.                       |
| `contentvalue`                          | `number`  | **Yes**     | Declared value of package contents in EUR.                          |
| `content_second_hand`                   | `boolean` | **Yes**     | Set to `true` if shipped goods are used/second-hand.                |
| `collection_date`                       | `string`  | No          | Date for package collection (format: `YYYY-MM-DD`).                 |
| `collection_time`                       | `string`  | No          | Collection time frame string (e.g., `"09:00 - 18:00"`).             |
| `dropoff_point_id`                      | `string`  | Conditional | Required if selected carrier service requires parcel shop drop-off. |
| `insurance`                             | `object`  | **Yes**     | Insurance configuration object.                                     |
| `insurance.insurance_selected`          | `boolean` | **Yes**     | Set to `true` to enable insurance protection.                       |
| `insurance.amount`                      | `number`  | Conditional | Required if `insurance_selected` is `true`.                         |
| `from`                                  | `object`  | **Yes**     | Origin sender details.                                              |
| `from.name`                             | `string`  | **Yes**     | Sender first name.                                                  |
| `from.surname`                          | `string`  | **Yes**     | Sender last name.                                                   |
| `from.phone`                            | `string`  | **Yes**     | Sender phone number.                                                |
| `from.street1`                          | `string`  | **Yes**     | Sender street address.                                              |
| `from.city`                             | `string`  | **Yes**     | Sender city.                                                        |
| `from.state`                            | `string`  | **Yes**     | Sender state/province.                                              |
| `from.country`                          | `string`  | **Yes**     | Sender country ISO code (e.g., `"IT"`).                             |
| `from.zip_code`                         | `string`  | **Yes**     | Sender postal / zip code.                                           |
| `from.email`                            | `string`  | No          | Sender email address.                                               |
| `from.company`                          | `string`  | No          | Sender company name.                                                |
| `to`                                    | `object`  | **Yes**     | Destination recipient details.                                      |
| `to.name`                               | `string`  | **Yes**     | Receiver first name.                                                |
| `to.surname`                            | `string`  | **Yes**     | Receiver last name.                                                 |
| `to.phone`                              | `string`  | **Yes**     | Receiver phone number.                                              |
| `to.street1`                            | `string`  | **Yes**     | Receiver street address.                                            |
| `to.city`                               | `string`  | **Yes**     | Receiver city.                                                      |
| `to.state`                              | `string`  | **Yes**     | Receiver state/province.                                            |
| `to.country`                            | `string`  | **Yes**     | Receiver country ISO code (e.g., `"BD"`).                           |
| `to.zip_code`                           | `string`  | **Yes**     | Receiver postal / zip code.                                         |
| `to.email`                              | `string`  | No          | Receiver email address.                                             |
| `to.company`                            | `string`  | No          | Receiver company name.                                              |
| `packages`                              | `array`   | **Yes**     | Non-empty array of package objects.                                 |
| `packages[].id`                         | `string`  | **Yes**     | Unique string identifier for package item.                          |
| `packages[].name`                       | `string`  | **Yes**     | Display name for package item.                                      |
| `packages[].weight`                     | `number`  | **Yes**     | Weight of package in **kg**.                                        |
| `packages[].width`                      | `number`  | **Yes**     | Width of package in **cm**.                                         |
| `packages[].height`                     | `number`  | **Yes**     | Height of package in **cm**.                                        |
| `packages[].length`                     | `number`  | **Yes**     | Length of package in **cm**.                                        |
| `customs`                               | `object`  | Conditional | Required if selected carrier service requires customs documents.    |
| `customs.customs_invoice_id`            | `string`  | Conditional | UUID reference from created `/customs-invoice` endpoint.            |
| `additional_data`                       | `object`  | **Yes**     | Internal route metadata and zone mappings.                          |
| `additional_data.postal_zone_id_from`   | `string`  | **Yes**     | Origin postal zone ID.                                              |
| `additional_data.postal_zone_name_from` | `string`  | **Yes**     | Origin postal zone display name.                                    |
| `additional_data.zip_code_id_from`      | `string`  | **Yes**     | Origin zip code ID.                                                 |
| `additional_data.postal_zone_id_to`     | `string`  | **Yes**     | Destination postal zone ID.                                         |
| `additional_data.postal_zone_name_to`   | `string`  | **Yes**     | Destination postal zone display name.                               |
| `additional_data.zip_code_id_to`        | `string`  | **Yes**     | Destination zip code ID.                                            |
| `additional_data.parcelIds`             | `array`   | **Yes**     | Array of string parcel IDs.                                         |

## 2. Get All Shipments

### Endpoint Details

- **Endpoint:** `/all`
- **Method:** `GET`
- **Example Request URL:** `${baseUrl}/all?state=DRAFT&page=1&limit=10&search=Poste`

---

### Query Parameters

| Parameter | Type     | Default  | Allowed Values | Description                                                                                                                                                                                               |
| :-------- | :------- | :------- | :------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `state`   | `string` | Optional | String         | Filter shipments by status state (e.g., `"DRAFT"` `"DELIVERED"`, `"IN_TRANSIT"`, `"READY_TO_PRINT"`, `"CANCELED"`, `"AWAITING_COMPLETION"`, `"INCIDENT"`, `"OUT_FOR_DELIVERY"`, `"RETURNED_TO_SENDER"`,). |
| `search`  | `string` | Optional | String         | Search keyword matching order references, shipment reference, carrier, service, names, cities, or tracking numbers.                                                                                       |
| `page`    | `number` | `1`      | Numeric        | Page number for pagination.                                                                                                                                                                               |
| `limit`   | `number` | `10`     | Numeric        | Maximum records per page.                                                                                                                                                                                 |

## 4. Update Shipment

### Endpoint Details

- **Endpoint:** `/:id`
- **Method:** `PATCH`
- **Example Request URL:** `${baseUrl}/cargo-5469c62b83e2`

---

### Path Parameters

| Parameter | Type     | Description                                         |
| :-------- | :------- | :-------------------------------------------------- |
| `id`      | `string` | additional_data.order_id of the shipment to update. |

---

### Request Body Specification

The update route reuses the same validation as shipment creation. Send the complete shipment payload, not only the fields being changed. The `:id` value is matched against `additional_data.order_id`, and only shipments with `state: "DRAFT"` can be updated.

#### Example Request Payload

Use the [Create Shipment](#1-create-shipment) request body and replace the fields that need to change.
