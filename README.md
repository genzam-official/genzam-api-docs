# Genzam API

Welcome to the public API documentation for Genzam IT. The Genzam API enables applications to integrate with Genzam services through authenticated HTTP requests.

This repository contains the documentation for the available API resources, usage flows, request formats, and response examples. Each resource has its own detailed reference guide.

## Documentation

The [Shipment API overview](<shipment/00. Overview.md>) is the starting point for the shipment API. It includes authentication details, common response formats, and links to the complete shipment reference and create flow guides.

For API access, contact Genzam IT support to request an API key and confirm which features are enabled for it.
